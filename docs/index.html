🚀 Quickstart

# Zero-setup install — developer profile into .bob/
npx everything-bob install

# Or install the full profile (all 37 skills, 7 hooks, 5 modes)
npx everything-bob install --profile full

# Install globally for all your projects
npx everything-bob install --global --profile developer

# Verify installation
npx everything-bob status
